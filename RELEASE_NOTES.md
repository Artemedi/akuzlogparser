Portable-версия AKUZ Log Explorer для Windows 10/11 x64. Python, Paramiko и криптографические библиотеки включены в EXE; устанавливать зависимости на рабочем компьютере не нужно.

### Скачать и запустить

- **AKUZLogExplorer-windows-x64.zip** — рекомендуемый пакет: EXE, конфиг-пример, инструкция и манифест сборки.
- **AKUZLogExplorer.exe** — отдельный исполняемый файл. При первом запуске создаёт конфиг-пример и файлы интерфейса рядом с собой.
- **SHA256SUMS.txt** — SHA-256 для EXE и ZIP.

Распакуйте пакет в доступную для записи папку, заполните `ConnectConf.cfg`, запустите EXE. Интерфейс откроется на `http://127.0.0.1:8765/`. Остановка — Ctrl+C в консоли.

При обновлении заменяйте только EXE. Сохраните свой конфиг, `reports/`, `cache/`, `downloads/` и `data/`. Заполненные конфиги и рабочие журналы в релиз не входят. EXE не подписан Authenticode.

### Изменения

- Даты первой записи автоматически определяются из имён `YYYYMMDD_*.log`; это действует и для старых отчётов в аналитике. Ручная корректировка имеет приоритет.
- Аналитика недоступна до завершения обработки всей выбранной пачки, включая прямой переход по URL.
- Исправлена миграция старого SQLite-индекса без столбца `relative_day`; текущая схема индекса — 5.
- Повторно выбранный неизменённый файл переиспользуется; выросший файл скачивается новым снимком целиком.
- Полностью обновлены руководства по запуску, отчётам, аналитике, архитектуре и сборке.

### Проверки

Windows CI: 38 Python-тестов, тест интерфейса на Node.js и проверка готового ZIP. EXE проверен из папки с кириллицей/пробелами и без Python в PATH: парсинг синтетического лога, календарная аналитика, native crypto, localhost HTTP, сохранение конфига и данных рядом с EXE.

Рабочий SSH-сервер и SMB-папка пользователя в проверках не использовались. Сжатие передачи и докачивание только добавленных байтов пока не реализованы.
