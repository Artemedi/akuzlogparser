AKUZ Log Explorer 4.4.0 — переносимая версия для Windows 10/11 x64. Python, Paramiko и необходимые библиотеки включены в EXE; Python на рабочем ПК не нужен.

### Что нового
- Третий источник — **Локальный .log / папка**. Укажите абсолютный путь к файлу или папке журналов на компьютере, где запущен EXE; SSH/SMB и настройка ConnectConf.cfg не нужны.
- Поддерживаются «Список файлов», «Последний лог», выбор до 30 журналов, дата из имени или вручную, отдельные/объединённые HTML-отчёты, аналитика и повторное использование снимков.
- Каталог читается без рекурсии, только .log. Исходники открываются на чтение и не меняются. Снимки хранятся рядом с EXE в downloads/; исходники очисткой кэша не удаляются.
- Исторические снимки одного источника, как и в 4.3.1, визуально группируются; правила дедупликации аналитики не изменялись.

### Файлы
- AKUZLogExplorer-windows-x64.zip — EXE, пример конфига, инструкция, BUILD_INFO.json с точным коммитом.
- AKUZLogExplorer.exe — отдельный portable EXE.
- SHA256SUMS.txt — SHA-256 обоих файлов.

Распакуйте ZIP в доступный для записи каталог и запустите EXE. Для локальных файлов выберите источник и введите путь, например D:\AKUZ\Logs. Для SSH/SMB заполните пример ConnectConf.cfg. По умолчанию интерфейс на http://127.0.0.1:8765/; при занятом порту укажите --port 8766. При обновлении сохраняйте собственный ConnectConf.cfg и downloads/, reports/, cache/, data/.

Windows CI: Python unit tests, Node.js UI tests и packaged EXE smoke test, включая реальный локальный .log из пути с кириллицей и пробелами, без Python в PATH. Рабочие медицинские данные и рабочий SSH/SMB-сервер не использовались. EXE не подписан Authenticode.
