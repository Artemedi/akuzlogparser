AKUZ Log Explorer 4.5.0 — Windows 10/11 x64 portable.

### Новое в 4.5.0
- Диагностический журнал производительности рядом с EXE: diagnostics/performance.txt.
  Локальное время, этап, начало/конец/ошибка, длительность, размер и счётчики;
  прогресс каждые 50 000 событий. Автоматическая ротация до трёх файлов по 3 МБ.
  Содержимое AKUZ-записей, пути журналов и параметры авторизации не записываются.
- Суточный профиль плотности событий по 24 часам вместо многостраничного списка
  дней/часов; переключение на хронологию, события / распознанные ошибки /
  среднее в день. Нажатие часа фильтрует список событий.
- Снимки одного источника в «Мои отчёты» теперь свернуты по умолчанию.
- Удалена галочка «Включая отчёты v4»; кнопка очистки кэша сохраняет отчёты.
- Скрипт scripts/refresh_report_ui.py обновляет интерфейс сохранённых v4-отчётов
  без перечитывания журналов и изменения data/, downloads/, cache/.

### Где искать задержку
Сравнивайте duration stage=source.fetch / report.generate / combined.merge /
analytics.refresh. Внутри генератора: generate.parse, generate.catalog.
В аналитике: analytics.inventory, analytics.ingest, analytics.export.

### Обновление
Остановите старый EXE, замените только AKUZLogExplorer.exe и запустите снова.
Сохраните ConnectConf.cfg и downloads/, reports/, cache/, data/.
При следующем запуске основной интерфейс обновится; существующие HTML-папки
reports/v4_* при необходимости отдельно обновите скриптом из репозитория.

### Состав
AKUZLogExplorer-windows-x64.zip, AKUZLogExplorer.exe, SHA256SUMS.txt.
ZIP содержит BUILD_INFO.json с точным коммитом и зависимостями.
Проверка: Python/Node-тесты и portable smoke test без Python в PATH.
EXE не подписан Authenticode.
