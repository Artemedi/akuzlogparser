# AKUZ Log Explorer 4.4.0 — Windows portable

Для Windows 10/11 x64. Python, pip, Paramiko и криптографические библиотеки уже включены в EXE. Устанавливать или скачивать зависимости на рабочем компьютере не нужно. Сервер требуется только для SSH/SMB: локальные .log и готовые отчёты работают без сети.

## Первый запуск

1. Полностью распакуйте ZIP в доступную для записи папку, например `D:\AKUZLogExplorer`.
2. Для SSH/SMB заполните ConnectConf.cfg рядом с AKUZLogExplorer.exe; для локальных файлов конфиг можно оставить примером.
3. Запустите `AKUZLogExplorer.exe`. Откроется браузер с `http://127.0.0.1:8765/`.
4. Выберите журналы и создайте отчёты. Дата подставляется из имени `YYYYMMDD_*.log`.
5. Для остановки нажмите Ctrl+C в открытой консоли. Закрытие вкладки браузера само по себе сервер не останавливает.

**Локальные журналы:** выберите «Источник → Локальный .log / папка», введите полный путь, например D:\AKUZ\Logs или D:\AKUZ\Logs\20260923_server.log, и нажмите «Список файлов» либо «Последний лог». Путь относится к компьютеру с запущенным EXE, не к удалённому браузеру. Обрабатываются только .log, каталог не обходится рекурсивно, исходники не меняются. Настройка ConnectConf.cfg не нужна. Путь запоминается только на время работы локального сервиса. UNC-пути обслуживаются отдельным источником Windows · SMB.

При первом запуске EXE распакует файлы интерфейса рядом с собой. Там же хранятся `downloads/`, `reports/`, `cache/`, `data/`. Сохраняйте всю папку приложения для переноса отчётов и офлайн-аналитики. EXE не устанавливает системную службу и не требует прав администратора.

Для SSH заранее проверьте ключ сервера и добавьте его в `%USERPROFILE%\.ssh\known_hosts` (например, штатным клиентом Windows OpenSSH). Неизвестные ключи приложение автоматически не принимает. Для SMB/UNC используются права текущего пользователя Windows.

## Обновление

Закройте приложение и замените только `AKUZLogExplorer.exe`. Сохраните свой `ConnectConf.cfg` и каталоги данных. При следующем запуске интерфейс обновится, конфиг останется прежним. Не распаковывайте конфиг-пример поверх своего заполненного файла.

Если конфиг отсутствует, EXE создаст пример `ConnectConf.cfg`, который нужно заполнить. Для запуска на другом порту: `AKUZLogExplorer.exe --port 8766`. Для запуска без открытия браузера: `AKUZLogExplorer.exe --no-browser`.

Архив включает `BUILD_INFO.json` с коммитом исходников и версиями сборки. Контрольная сумма ZIP поставляется отдельно в `SHA256SUMS.txt`. Заполненный конфиг и рабочие журналы в поставку не входят.

EXE также доступен отдельным файлом в релизе: при первом запуске он создаст конфиг-пример и файлы интерфейса рядом с собой. ZIP удобнее для первого знакомства — в нём уже есть конфиг и эта инструкция. Текущая сборка не подписана Authenticode.
