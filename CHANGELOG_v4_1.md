# AKUZ Log Explorer v4.1 — 2026-09-22

- Снимок активно пополняемого `.log`: фиксированная граница байтов непосредственно перед передачей; дописывание в конец разрешено.
- Отсев недописанной последней физической строки только в активном локальном снимке; пересчёт SHA-256 после отсечения.
- Переинвентаризация выбранных файлов перед проверкой кэша; повторный выбор неизменённого файла использует существующий отчёт.
- Устройство/inode проверяются при открытии и после скачивания; ротация и усечение по-прежнему приводят к ошибке, временный `.part` удаляется.
- После успешной загрузки панель выбора автоматически сворачивается. Есть ручное раскрытие/сворачивание; при ошибке панель остаётся доступной.
- Формат ConnectConf.cfg и хранилища v4 не изменён; Python 3.9+, Paramiko, Windows BAT без дополнительных зависимостей.

Ограничение: не является атомарным файловым снимком, перезапись содержимого на месте без усечения может быть не обнаружена.


## Standalone HTML — Windows file-log collector

- Второй источник `Windows · SMB / UNC` через конфиг [windows], без WinRM и SMB-паролей в HTML.
- Снимок сетевого активного файла ограничен размером при открытии; хвост незаконченной строки не парсится.
- Выбор дат/нескольких файлов, кэш, отдельные и объединённые отчёты используются общие с Linux.
- Очистка кэша учитывает обе настроенные папки загрузки и не трогает произвольные файлы.
- VCLib/Source-Aware Diagnostics не являются частью akuzlogparser.

- Windows TraceLogger поддерживает отдельный формат строк, включая многострочные сообщения.
- Генератор HTML использует единый index.html / event.html / style.css; чистый старт локального сервиса показывает пустой обзор.
- Регрессионные тесты выполняются без сети и реальных медицинских данных.
